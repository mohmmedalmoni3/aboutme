# Project Images

This folder contains screenshots for your portfolio projects.

## Required Images

Add your project screenshots with the following filenames:

1. **ieeeanu-app.jpg** - Screenshot of IEEE ANU Store (Featured Project)
2. **justicecfw.jpg** - Screenshot of Justice City Framework (FiveM)
3. **tryjo-ecommerce.jpg** - Screenshot of TRY JO E-commerce Store
4. **atp-security-dashboard.jpg** - Screenshot of ATP Security Dashboard
5. **user-management-dashboard.jpg** - Screenshot of User Management Dashboard

## Image Guidelines

- **Recommended size**: 1200x800 pixels (or similar aspect ratio)
- **Format**: JPG or PNG
- **Quality**: High quality but optimized for web (under 500KB if possible)
- **Content**: Show the main interface/dashboard of your project

## How to Add Images

1. Take a screenshot of each project
2. Resize/crop to appropriate dimensions if needed
3. Save with the exact filenames listed above
4. Place them in this `images` folder
5. Refresh your portfolio page to see the images

The HTML is already configured to load these images automatically once they're added.
